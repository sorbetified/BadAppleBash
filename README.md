# **BadAppleBash - Bad Apple!! for the BASH terminal**

Hi guys! I decided to make Bad Apple!! for BASH, because most attempts at making this project either:

- A) Are to complicated
- B) Get desynced from audio (if there's any)
- C) Have low frame rates

and the installation is ***DEAD SIMPLE***:

1. First, install dependencies (May vary for other linux distributions, but with Debian-Based Systems):

```bash
sudo apt install git mpv
```

2. Clone the Repo:

```bash
git clone https://github.com/sorbetified/BadAppleBash.git
```
3. CD into the directory:

```bash
cd BadAppleBash
```

4. give bad-apple.sh Execute premissions:

```bash
chmod +x bad-apple.sh
```

5. Run the program:

```bash
./bad-apple.sh
```

and enjoy watching Bad Apple in your terminal :)
